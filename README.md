# Ripelime
A project queue manager to discuss project ideas with your team.

# How to use
1. Have git installed, ensure that you have write access to the repo with the git installed on your system and ensure that git is in $PATH.
2. Open the app
3. Enter the repo url

# Conventions
tabs:              4 spaces
variables/constants:  snake_case
global functions:     `PascalCase()` if object oriented, `camelCase()` if free
types/structs:        PascalCase()
macros:               UPPER_CASE

```c
void func() { // <- brace here
    /* ... */
}

for (int i=0;  i < 100;  ++i)
{  // <- brace below, two spaces between expressions
    /* for and while are loops so conventionally put braces below the keyword */
}

if (cond) { // <- brace here
    /* ...  */
}

```
